# WinClips

macOS의 [Maccy](https://maccy.app/)처럼, 복사한 내용을 기억해 두었다가 단축키 하나로 다시 붙여넣는 Windows용 클립보드 기록 앱입니다.

- **텍스트, 파일(탐색기에서 복사), 이미지(스크린샷 등)** 를 기록합니다.
- 기본 단축키 **`Ctrl+Shift+V`** 로 목록을 열고, 고른 항목을 바로 쓰던 창에 붙여넣습니다.
- 단축키는 원하는 조합으로 바꿀 수 있습니다.
- 시스템 트레이에 상주하고, Windows 로그인 시 자동으로 시작합니다.
- 화면 테마(라이트/다크)를 따라갑니다.

## 설치

1. [Releases](https://github.com/fellow-survivor-studio/win-clips/releases/latest)에서 `WinClips-<버전>-x64.msi` 를 내려받아 실행합니다.
2. 관리자 권한 없이 현재 사용자에게만 설치됩니다 (`%LOCALAPPDATA%\Programs\WinClips`).
3. 설치가 끝나면 바로 실행되고, 시작 메뉴에 **WinClips** 가 생기며, 다음 로그인부터 자동으로 시작합니다.

서명되지 않은 설치 파일이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행** 을 누르면 설치됩니다.

설치 없이 쓰려면 `WinClips-<버전>-x64-portable.exe` 를 원하는 폴더에 두고 실행하면 됩니다. 두 파일 모두 .NET 런타임이 들어 있어 따로 설치할 것이 없습니다 (Windows 10/11 64비트).

### 제거

**설정 → 앱 → 설치된 앱 → WinClips → 제거**. 실행 중인 앱은 자동으로 종료되고, 자동 시작 등록과 시작 메뉴 항목도 함께 지워집니다. 클립보드 기록(`%LOCALAPPDATA%\ClipboardHistory`)은 남겨 두므로, 기록까지 지우려면 그 폴더를 삭제하세요.

## 사용법

| 동작 | 방법 |
|---|---|
| 기록 목록 열기/닫기 | **`Ctrl+Shift+V`** (바꿀 수 있음) 또는 트레이 아이콘 왼쪽 클릭 |
| 검색 | 목록이 열린 상태에서 바로 입력 (부분 일치, 대소문자 무시) |
| 항목 이동 | `↑` `↓` (`PageUp` `PageDown` 은 8칸씩), 마우스를 올려도 선택됨 |
| 붙여넣기 | `Enter`, 클릭, 또는 `Ctrl+1` ~ `Ctrl+9` (목록의 1~9번째 항목) |
| 고정 / 고정 해제 | `Ctrl+P` (고정한 항목은 위에 표시되고 자동으로 지워지지 않음) |
| 항목 삭제 | `Ctrl+Delete` |
| 고정하지 않은 항목 모두 삭제 | `Ctrl+L` |
| 닫기 | `Esc` 또는 목록 바깥 클릭 |

단축키로 목록을 열면, 고른 항목이 목록을 열기 직전에 쓰던 창에 바로 붙여넣어집니다. 트레이 아이콘으로 열었을 때는 붙여넣을 창이 없으므로 클립보드에 복사만 합니다.

같은 내용을 다시 복사하면 중복으로 쌓이지 않고 맨 위로 올라옵니다. 고정하지 않은 항목은 최근 200개까지 보관합니다.

### 단축키 바꾸기

1. 트레이 아이콘을 **오른쪽 클릭 → 단축키 변경...**
2. 원하는 조합을 그대로 누릅니다. Ctrl, Alt, Shift 중 하나 이상과 키 하나를 함께 눌러야 합니다 (예: `Ctrl+Shift+V`, `Ctrl+Alt+F8`, `Alt+Space`).
   쓸 수 있는 키: 영문자, 숫자, F1~F12, Space, Enter, Tab, Insert, Delete, Home, End, PageUp, PageDown, 방향키.
3. **저장** (또는 `Enter`) 을 누르면 바로 적용되고, 다음 실행에도 유지됩니다.

다른 프로그램이 이미 쓰고 있거나 Windows가 예약한 조합이면 저장되지 않고 이유가 표시됩니다. **기본값** 버튼은 `Ctrl+Shift+V` 로 되돌리고, **취소** 또는 `Esc` 로 닫습니다.

### 트레이 메뉴

| 메뉴 | 설명 |
|---|---|
| 기록 열기 | 목록 열기 (오른쪽에 현재 단축키 표시) |
| 단축키 변경... | 위의 단축키 바꾸기 |
| Windows 시작 시 자동 실행 | 로그인할 때 자동으로 시작 (설치하면 켜져 있음) |
| 고정하지 않은 기록 지우기 | 고정한 항목만 남기고 모두 삭제 |
| 데이터 폴더 열기 | 기록이 저장된 폴더를 탐색기로 열기 |
| 종료 | 앱 종료 |

## 기록되는 것

| 종류 | 목록 표시 | 붙여넣기 |
|---|---|---|
| 텍스트 | 앞부분 미리보기 | 텍스트 |
| 파일 (탐색기에서 `Ctrl+C`) | 파일 이름 | 파일 복사 (탐색기에 붙여넣기 가능) |
| 이미지 (스크린샷, 그림판, 브라우저 "이미지 복사") | `[Image 가로x세로]` + 아래쪽 미리보기 | 이미지 |

- 비밀번호 관리자처럼 "기록하지 말 것" 표시를 붙여 복사하는 앱의 내용은 기록하지 않습니다.
- 1MB를 넘는 텍스트, 30MB를 넘는 이미지는 기록하지 않습니다.

## 데이터 위치

모두 `%LOCALAPPDATA%\ClipboardHistory\` 아래에 있으며, 컴퓨터 밖으로 보내지 않습니다.

| 파일 | 내용 |
|---|---|
| `history.db` | 기록 목록 (SQLite) |
| `images\` | 이미지 원본 (압축 저장) |
| `settings.json` | 단축키 설정 |
| `app.log` | 실행 로그 |

## 알려진 제한

- 관리자 권한으로 실행된 창에는 붙여넣기가 막힐 수 있습니다 (Windows 보안 정책). 이때는 항목이 클립보드에 복사되어 있으니 직접 `Ctrl+V` 를 누르면 됩니다.
- 특정 앱을 기록에서 빼는 설정은 아직 없습니다.
- 설치 파일이 코드 서명되어 있지 않습니다.

## 빌드

필요: Windows 10/11, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
.\build.ps1
```

테스트를 돌린 뒤 `artifacts\` 에 설치 파일(`.msi`)과 단독 실행 파일(`-portable.exe`)을 만듭니다. 설치 파일은 [WiX Toolset](https://wixtoolset.org/) 5로 만들며, 빌드할 때 NuGet에서 자동으로 받아 옵니다.

개발 중 실행과 테스트:

```powershell
dotnet run --project src\ClipboardHistory
dotnet test
```

### 구성

| 경로 | 내용 |
|---|---|
| `src/ClipboardHistory.Core` | 기록 저장소, 단축키 해석, 설정, 클립보드 데이터 변환 (Windows UI와 무관, 테스트 대상) |
| `src/ClipboardHistory` | WPF 앱: 목록 창, 단축키 변경 창, 트레이 아이콘, Win32 클립보드/단축키/붙여넣기 |
| `tests/ClipboardHistory.Tests` | 단위 테스트 (xUnit) |
| `installer` | MSI 설치 파일 (WiX) |
| `build.ps1` | 테스트, 배포용 빌드, 설치 파일 생성 |
